# 🌍 Terraform Project 1  

## 📖 Overview  
This project is a **Terraform-based Infrastructure as Code (IaC)** setup.  
It demonstrates how to create and manage cloud resources automatically, ensuring reproducibility and scalability.  

---

## 🚀 Features  
- ✅ Written using **Terraform HCL**  
- ✅ Infrastructure is managed as **Code**  
- ✅ Supports modular and reusable configurations  
- ✅ Easy initialization, planning, and applying  

---

## 🛠️ Technologies Used  
- **Terraform**  
- **AWS Cloud Provider**  
- **Linux (Rocky Linux VM)**  
- **Git & GitHub** for version control  

---

## ⚡ How to Use  
1. Clone this repository:  
   ```bash
   git clone https://github.com/shahdahmed123/Terraform-project_1.git
   cd Terraform-project_1/lab2-vpc


2.Initialize Terraform:
terraform init

3.Preview infrastructure changes:
terraform plan

4.Apply the changes (create resources):
terraform apply

5.Destroy resources when no longer needed:
terraform destroy
